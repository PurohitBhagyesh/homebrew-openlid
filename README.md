# PurohitBhagyesh Openlid

## How do I install these formulae?

`brew install purohitbhagyesh/openlid/<formula>`

Or `brew tap purohitbhagyesh/openlid` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "purohitbhagyesh/openlid"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
